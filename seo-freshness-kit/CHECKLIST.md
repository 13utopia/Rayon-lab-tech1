# After Cursor says it is done

You do these. Cursor cannot click hosting panels.

- [ ] WordPress: plugin **Activated**
- [ ] WordPress: Settings → Permalinks → **Save**
- [ ] Open `/updates/` — you see a list
- [ ] Open one update URL — you see a page
- [ ] Open `/llms.txt` — plain text, not a theme page
- [ ] Add cron (Tue/Fri): the curl URL Cursor printed
- [ ] Google Search Console → submit sitemap

If `/updates/` is 404: Permalinks → Save again.
