# SEO Freshness Kit

This folder is the **entire product**. Zip it and send it. You do not need any other repo.

## You (the person receiving this)

1. Open **START-HERE.txt**
2. Do those 5 steps
3. Stop

If you use Cursor: the only chat message you send is the text inside **COPY-THIS-PROMPT.txt**.

## What you get

- Unique `/updates/{id}` pages on a weekday schedule (default Tue/Fri)
- Sitemap lastmod
- IndexNow ping (Bing/Google-compatible notify)
- `/llms.txt` for AI crawlers
- JSON-LD on list + posts
- Works on **WordPress**, **any PHP host**, or **Vercel**
